# ItemBattle

A simple minecraft plugin based on this video: [Click to see](https://www.youtube.com/watch?v=5pMeM_uY0M0)

The challenge is collecting items in a team (random items), and whoever collects the most at the end wins the round.

### Some extra features are: 

- skips if an item is too hard to get (elytra for example, you get the item if you skip)
- a backpack for your team
- /msg "Player" "Message"
- /msgteam

### Admins:

Create teams using **/ib teamconfig**

Start the game using **/ib start**

### Compile it yourself using `./gradlew build`

## Have fun!
